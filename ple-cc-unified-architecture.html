ครอบคลุมทุก Scenario ตั้งแต่การข้ามสถานี, การตรวจย้อนหลัง (Local Review), การสลับผู้เข้าสอบใน Carousel, การกู้คืนเซสชันเมื่อเน็ตหลุด ไปจนถึงการแยก Channel ของ Typing Indicator

หมวดหมู่ (Category) รายการบั๊ก / จุดเสี่ยง (Bugs #) กลไกสถาปัตยกรรมที่ป้องกัน (Architectural Safeguard)
1. การป้องกันการข้ามสถานีซ้อน (Anti-Skip & Single Master) Bugs #1, #2, #3, #4, #6, #14 ใช้ฟังก์ชัน isSingleMasterStationController() จำกัดสิทธิ์สั่งเลื่อนสถานีอัตโนมัติให้มีเพียง 1 เครื่องต่อห้อง, เก็บ _timeoutPopupTimerId เพื่อสั่งยกเลิกทันทีเมื่อมีคนกดข้ามมือ, ตรวจสอบ expectedFromIdx ก่อนเขียน Firebase และล็อก _expiredForStationKey ไม่ให้หมดเวลาซ้ำในรอบเดิม
2. โหมดตรวจย้อนหลังแยกอิสระ (Universal Local Review Isolation) Bugs #5, #9, #10, #16, #20, #21, #22 เมื่อกรรมการคลิกสถานีใน Minimap หรือกดปุ่ม Prev/Next หรือสลับผู้เข้าสอบใน Carousel จะเข้าสู่ SimState._isLocalReview = true แยกจากตัวแปรสถานีกลาง บล็อกการเขียนทับจาก Snapshot เบื้องหลัง ดึงคำตอบเติมคำและโจทย์ของสถานี/ผู้เข้าสอบที่กำลังรีวิวมาแสดง และพาออกจากโหมดรีวิวพร้อมแจ้งเตือนเมื่อห้องเปลี่ยนสถานี
3. ความแม่นยำของเวลาและการซิงก์ (Server Time & Snapshot Queue) Bugs #7, #8, #11, #12, #13 ใช้เวลาเซิร์ฟเวอร์ getSyncedNow() (ผ่าน .info/serverTimeOffset) แทน Date.now() ทุกจุดรวมถึงตอนสลับแท็บกลับมา, จัดคิว _pendingRoomState ป้องกัน Snapshot ตกหล่นขณะโหลดเคส, ลบ findIndex ที่ทำให้สถานีพัก (REST) ซ้ำกันกระโดดข้าม และปลดล็อก status === 'results' ให้สรุปผลได้ทันที
4. ความถูกต้องของคะแนนและคำตอบ (Score & Blank Data Integrity) Bugs #15, #17, #18, #23, #25 จำกัดให้เฉพาะ Examiner เท่านั้นที่เขียน scoresByStation ในโหมด Standard, คำนวณรหัสผู้เข้าสอบใน Carousel จากรอบจริง cachedRoom.currentStationIdx เสมอ, สั่ง flushPendingExamineeBlanks() ทันทีก่อนเปลี่ยนสถานีหรือจบสอบ และแยก Path ของ stationFeedbacks ตามโต๊ะย่อย/ผู้เข้าสอบแต่ละคน
5. ความเสถียรของที่นั่งและเครือข่าย (Atomic Seats, Reconnect & Chat) Bugs #19, #24, #26 ใช้ roomRef.transaction(...) ป้องกันการแย่งเก้าอี้ Carousel พร้อมกัน, กู้คืนที่นั่งและตั้ง roleSelectedThisSession = true อัตโนมัติเมื่อรีเฟรชหน้าจอ และย้ายสถานะกำลังพิมพ์แชทไปยัง roomTyping/{roomId} นอก Tree ห้องสอบเพื่อลดภาระการบรอดแคสต์
1. เมื่อตัวจับเวลานับถอยหลังถึง 00:00 Fix Bugs #4, #14
เงื่อนไขเหตุการณ์: เมื่อ SimState.timerValue ลดลงจนน้อยกว่าหรือเท่ากับ 0 ในฟังก์ชัน startLocalCountdown
พฤติกรรมเดิม (สาเหตุบั๊ก): หากมี Snapshot เข้ามาซ้ำตอนเวลาเป็น 0 อาจเกิดการเรียกหมดเวลาซ้ำซ้อน หรือสถานะ timerRunning ค้างเมื่อออกก่อนจบฟังก์ชัน
พฤติกรรมที่ถูกต้อง: ตั้งค่า SimState.timerRunning = false ทันที และผูกกุญแจ _expiredForStationKey เข้ากับดัชนีสถานีและเวลาเริ่ม เพื่อรับประกันว่าการหมดเวลาจะทำงานเพียงครั้งเดียวต่อรอบ const expiryKey = `${expiredIdx}_${roomRefObj?.timerStartedAt || 'solo'}`;
2. หน้าต่างแจ้งหมดเวลาและการยกเลิก Timer ค้าง Fix Bugs #2, #3
เงื่อนไขเหตุการณ์: เมื่อเวลาแตะ 00:00 ฟังก์ชัน showTimeoutPopup เปิด Modal นับถอยหลัง 3 วินาที แต่ผู้คุมสอบกดปุ่มเลื่อนสถานีด้วยตนเองก่อนครบ 3 วินาที
จุดเสี่ยง Race Condition: หากไม่ยกเลิก setTimeout ของ Popup เมื่อครบ 3 วินาที Callback ที่ค้างอยู่จะสั่งเลื่อนสถานีซ้ำอีกครั้ง (กระโดดข้ามจากสถานี 2 ไป 3 ทันที)
มาตรการป้องกัน: เก็บไอดีไว้ใน SimState._timeoutPopupTimerId เพื่อสั่ง clearTimeout ทันทีเมื่อเปลี่ยนสถานี และส่ง expectedFromIdx ไปตรวจสอบซ้ำก่อนอัปเดต Firebase clearTimeout(SimState._timeoutPopupTimerId); nextStation(expiredIdx);
3. สิทธิ์ Single Master ในการสั่งเลื่อนสถานี Fix Bug #1
เงื่อนไขเหตุการณ์: เมื่อหมดเวลาในโหมด Standard Room (ที่มีทั้ง Host และ Examiner) หรือในโหมด Cohort Breakout / Carousel Rotation
กฎการควบคุม (Single Master Authority): ในห้องใหญ่ (Breakout/Carousel) เฉพาะ Super Host เท่านั้นที่สั่งเลื่อนรอบ ส่วนในห้อง Standard หากมี Examiner อยู่ ให้ Examiner เป็นผู้สั่งเลื่อนเพียงคนเดียว ป้องกัน Host และ Examiner ยิงคำสั่งพร้อมกัน
โค้ดบังคับใช้: function isSingleMasterStationController() { ... }
4. การปิดการสอบโดยไม่เกิด Deadlock Fix Bug #11
เงื่อนไขเหตุการณ์: เมื่อห้องสอบได้รับ status = 'results' จาก Firebase หรือมีผู้เข้าสอบรีเฟรชหน้าจอเข้ามาตอนสอบเสร็จพอดี
จุดเสี่ยงเดิม: การตั้ง SimState.isFinishingExam = true ก่อนเรียก finishExamSimulation() ทำให้เกิด Deadlock เพราะฟังก์ชันเห็นว่ากำลังจบสอบอยู่แล้วจึง Return ออกทันที
มาตรการป้องกัน: สร้างรายการสถานีจากห้องสอบหากยังว่างอยู่ และให้ finishExamSimulation() เป็นผู้ตั้งค่า SimState.isFinishingExam = true ด้วยตนเองเมื่อเริ่มทำงาน if (!SimState.isFinishingExam && !SimState.isExamFinished) await finishExamSimulation();
5. โหมดตรวจย้อนหลังครบวงจร (Universal Local Review) Fix Bugs #5, #16, #20
การใช้งาน: กรรมการสามารถคลิกเลือกสถานีที่ผ่านมาแล้วบน Minimap หรือกดปุ่มก่อนหน้า/ถัดไป หรือคลิกเลือกชื่อผู้เข้าสอบรอบก่อนหน้าในโหมด Carousel ได้อย่างอิสระ
การแสดงผลครบทุกส่วน: ฟังก์ชัน renderScenarioAndNotesForReview อัปเดตทั้งโจทย์, ข้อมูลผู้ป่วย, อุปกรณ์, เฉลยกรรมการ, ช่องคอมเมนต์ และคำตอบเติมคำของสถานีที่กำลังรีวิวให้ตรงกันทั้งหมด
การแยกสถานะ (State Isolation): ใช้ตัวแปร SimState._isLocalReview และ _localReviewStationIdx โดยไม่ไปแก้ไข currentStationIdx ของห้องสอบจริง
6. การติ๊กและรีเซ็ตคะแนนขณะตรวจย้อนหลัง Fix Bugs #9, #10, #22
การป้องกันการเขียนทับจาก Snapshot: ขณะที่ SimState._isLocalReview เป็น true ระบบจะบล็อกไม่ให้ applyRoomState นำคะแนนของสถานีปัจจุบันมาเขียนทับ DOM ของหน้าจอที่กรรมการกำลังตรวจย้อนหลังอยู่
ความแม่นยำของเป้าหมายคะแนน: ทั้งการติ๊กให้คะแนนและการกดปุ่มรีเซ็ตคะแนน (resetCurrentStationChecklist) จะอ้างอิงสถานีและรหัสผู้เข้าสอบที่กำลังรีวิวอยู่โดยตรง
พาทข้อมูล Firebase: participantScores/[reviewPartId]/stations/[assignedStationNum]
7. การแจ้งเตือนและดึงกลับเมื่อเปลี่ยนสถานี/รอบ Fix Bugs #16, #18
เงื่อนไขเหตุการณ์: เมื่อ Super Host สั่งเปลี่ยนสถานีในโหมด Breakout หรือเปลี่ยนรอบหมุนเวียนในโหมด Carousel
กลไกการทำงาน: ในโหมด Breakout ระบบจะล้างสถานะรีวิวและพากรรมการไปยังสถานีใหม่ทันที ส่วนในโหมด Carousel หากกรรมการกำลังตรวจย้อนหลังอยู่ ระบบจะส่งเสียงเตือนและอัปเดตแบนเนอร์แจ้งว่ามีผู้เข้าสอบคนใหม่เข้าประจำฐานแล้ว
การสลับ Listener อัตโนมัติ: เมื่อเปลี่ยนรอบ Carousel ระบบจะสลับ Listener คำตอบเติมคำและช่อง Feedback ไปยังผู้เข้าสอบคนใหม่ทันที
8. การป้องกันผู้เข้าสอบเขียนทับคะแนนกรรมการ Fix Bug #15
ข้อกำหนดเข้มงวด: ในโหมด Standard Room หากผู้สร้างห้อง (Host) เลือกบทบาทเป็นผู้เข้าสอบ (Examinee) เครื่องของผู้เข้าสอบต้องไม่เขียน studentScores ที่ว่างเปล่าไปทับคะแนนของ Examiner
การควบคุม: อนุญาตให้แนบ scoresByStation ลง Firebase เฉพาะเมื่อผู้ใช้งานมีบทบาทเป็น Examiner เท่านั้น
โค้ดบังคับใช้: if (!SimState.cachedRoom?.isSuperHost && SimState.examMode === 'standard' && SimState.role === 'examiner')
9. เน็ตหลุด/รีเฟรชแล้วกลับมาที่นั่งเดิมทันที Fix Bug #24
ปัญหาเดิมที่พบ: เมื่อผู้เล่นกดรีเฟรชและเข้าห้องเดิม หากไม่ได้ตั้งค่า roleSelectedThisSession = true หน้าต่างเลือกบทบาทจะเด้งขึ้นมาใหม่ และเมื่อกดยืนยันจะไปสั่งล้างที่นั่งในโต๊ะ Breakout หรือฐาน Carousel ทิ้ง
การกู้คืนที่นั่งอัตโนมัติ: เมื่อตรวจพบว่าเป็นสมาชิกเดิม (isExistingMember) ระบบจะตั้ง roleSelectedThisSession = true ทันที พร้อมกู้คืน myBreakoutTableId หรือ myCarouselStation และสถานะ isHost ลง Session Storage if (isExistingMember) { SimState.roleSelectedThisSession = true; ... }
10. ระบบล็อคห้องสอบ (Host Room Lock 🔒) Security Barrier
การสั่งงาน: ผู้คุมสอบ (Host หรือ Super Host) กดปุ่มไอคอนกุญแจ 🔒 เพื่อสั่ง toggleRoomLock() ซึ่งจะส่ง isLocked: true ไปยัง Firebase RTDB
การบล็อกบุคคลภายนอก: หากบุคคลใหม่พยายามเข้าห้องสอบ ระบบจะแสดง Modal: "🔒 ห้องสอบถูกล็อกโดยผู้คุมสอบ - ห้องสอบปิดรับสมาชิกใหม่ (Room Locked)"
ข้อยกเว้นพิเศษ (Bypass Rule): สมาชิกเดิมที่มีชื่ออยู่ในห้องแล้ว (isExistingMember === true) จะได้รับการยกเว้นและสามารถกลับเข้าห้องได้เสมอแม้ห้องจะถูกล็อคอยู่ก็ตาม if (roomData.isLocked && !isExistingMember) { showRoomBlockedModal(...); }

12. ห้องสอบเริ่มแล้วห้ามเข้า (Mid-Exam Barrier) Exam Integrity
เงื่อนไขเหตุการณ์: เมื่อสถานะห้องสอบเปลี่ยนเป็น status === 'running' หรือ status === 'countdown'
การบล็อกคนใหม่: บุคคลที่ไม่ได้อยู่ในรายชื่อเดิม (!isExistingMember) จะถูกบล็อกทันทีด้วย Modal: "⛔ ไม่สามารถเข้าห้องสอบได้ในขณะนี้ - การสอบได้เริ่มต้นขึ้นแล้ว (Exam in Progress)"
เหตุผลทางสถาปัตยกรรม: เพื่อรักษาลำดับการวนสถานี (Rotation Order), ป้องกันตัวหารคะแนนของรุ่นคลาดเคลื่อน, และรักษาความเป็นธรรมของผู้เข้าสอบทุกคน if ((room.status === 'running' || room.status === 'countdown') && !isExistingMember)
13. การซิงก์นาฬิกาเซิร์ฟเวอร์ (Server Clock Sync) Fix Bugs #8, #13
ปัญหานาฬิกาเครื่องคลาดเคลื่อน: หากนาฬิกาในคอมพิวเตอร์หรือไอแพดของผู้เข้าสอบเดินเร็วกว่าปกติ การใช้ Date.now() จะทำให้เวลานับถอยหลังหมดเร็วกว่าเครื่องอื่น หรือตัดจบหน้าจอ 5-4-3-2-1 ทันที
กลไกแก้ไข: ใช้ฟังก์ชัน getSyncedNow() ซึ่งบวกค่าชดเชยเวลาจาก Firebase (.info/serverTimeOffset) ในทุกจุดที่คำนวณเวลาสอบ รวมถึงเมื่อผู้ใช้สลับหน้าจอกลับมา (visibilitychange) const elapsed = Math.floor((getSyncedNow() - room.timerStartedAt) / 1000);
14. การรองรับสถานีพัก (REST) หลายจุดโดยไม่ข้ามสถานี Fix Bug #7
สาเหตุบั๊กเดิม: ในการสอบ OSPE 16 สถานีที่มีสถานีพัก 2 จุด ทั้งสองจุดจะมี caseId เป็น 'REST' เหมือนกัน หากระบบใช้ findIndex(c => c.caseId === room.caseId) เมื่อถึงสถานีพักจุดที่ 2 ระบบจะดีดกลับไปสถานีพักจุดที่ 1
วิธีแก้ปัญหา: ยกเลิกการค้นหาด้วย caseId และใช้ดัชนี room.currentStationIdx โดยตรงในการระบุสถานีปัจจุบันเสมอ targetIdx = Number(room.currentStationIdx);
15. คิวรับข้อมูล Snapshot ขณะโหลดเคส (_pendingRoomState) Fix Bug #12
เงื่อนไขเหตุการณ์: เมื่อ applyRoomState กำลังทำงานแบบ async (เช่น รอถอดรหัสเคสหรือสร้างสถานี) แล้วมี Snapshot ใหม่ที่สำคัญกว่า (เช่น สั่งเริ่มจับเวลา หรือสั่งเปลี่ยนสถานี) ส่งเข้ามาพอดี
การป้องกันข้อมูลตกหล่น: แทนที่จะทิ้ง Snapshot ใหม่ไปเฉยๆ ระบบจะเก็บไว้ในตัวแปร _pendingRoomState และประมวลผลต่อทันทีในบล็อก finally if (_isApplyingRoomState) { _pendingRoomState = room; return; }
16. สูตรคำนวณผู้เข้าสอบของกรรมการประจำฐาน Carousel Fix Bug #17
ความพิเศษของโหมด Carousel: กรรมการที่ประจำอยู่ฐานที่ K จะมีค่า SimState.currentIdx คงที่เท่ากับ K-1 ตลอดการสอบ ในขณะที่รอบการหมุนเวียนจริงอยู่ที่ room.currentStationIdx (r)
การอ้างอิงรอบที่ถูกต้อง: ทุกฟังก์ชันการตรวจคะแนน ดูคำตอบเติมคำ และรีเซ็ตคะแนนของกรรมการในโหมด Carousel จะอ่านค่ารอบ r จาก SimState.cachedRoom.currentStationIdx เสมอ const currStartStNum = ((myCarouselStation - 1 - r + N) % N) + 1;
17. การบันทึกคำตอบเติมคำทันทีเมื่อหมดเวลา (Blank Flush) Fix Bug #25
จุดเสี่ยงเดิม: การพิมพ์คำตอบในช่องว่าง [BLANK:...] มีหน่วงเวลา Debounce 350ms หากผู้เข้าสอบพิมพ์คำตอบในวินาทีสุดท้ายก่อนตัดเปลี่ยนสถานี คำตอบอาจยังไม่ถูกส่งขึ้น Firebase
กลไกป้องกันคำตอบหาย: ฟังก์ชัน flushPendingExamineeBlanks() จะถูกเรียกทำงานทันทีเป็นอันดับแรกเมื่อเริ่มเปลี่ยนสถานี (jumpToStation / renderStation) และเมื่อจบการสอบ (finishExamSimulation) if (typeof flushPendingExamineeBlanks === 'function') flushPendingExamineeBlanks();
18. การแยกพื้นที่ Feedback รายบุคคลและ Typing Channel Fix Bugs #23, #26
การแยกข้อเสนอแนะ (Scoped Feedbacks): ข้อความข้อเสนอแนะของกรรมการถูกแยกเก็บตามโต๊ะสอบย่อย (breakouts/[tableId]/stationFeedbacks) หรือตามผู้เข้าสอบแต่ละคนใน Carousel (participantScores/[partId]/stationFeedbacks) ไม่ปะปนกันทั้งห้อง
การแยกสัญญาณกำลังพิมพ์แชท (Typing Root Isolation): ย้ายสัญญาณกำลังพิมพ์ออกจาก rooms/[roomId] ไปยังพาทแยกอิสระ roomTyping/[roomId] เพื่อไม่ให้ทุกการกดแป้นพิมพ์ไปกระตุ้น Listener หลักของห้องสอบ return `roomTyping/${SimState.roomId}/breakouts/${tableId}/st_${stNum}`;
